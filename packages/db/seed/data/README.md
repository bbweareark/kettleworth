# Seed data

- `free-exercise-db.json`, 876 exercises from https://github.com/yuhonas/free-exercise-db (The Unlicense / public domain). Images are served from that project's GitHub Pages at `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/<id>/<n>.jpg` and are **labelled as placeholder stills** in the product until Kettleworth footage exists.
- `curated.ts`, Kettleworth-authored cues, common mistakes, safety notes and aliases for the core lifts, merged over the imported rows.
- `recipes.ts`, Kettleworth-authored recipe set with per-serving macros and ingredient costs.
